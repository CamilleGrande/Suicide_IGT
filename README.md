# Suicide_IGT
This repository holds the scripts necessary to run the analysis for the IGT Computational modelling in high suicide phenotypes manuscript. 

"SPAD_2026": holds the scripts to run the IGT modelling part in the SPAD sample (older adults)
"Jena_2026": holds the scripts to run the IGT modelling part in the SUICIDE-DECIDE sample (younger adults)

"Descriptives": holds the scripts to get the descriptives stats in both samples

"Behavior": holds the scripts to run the behavioral, classical analysis of the IGT in both samples (results in Supplements)

"Imputation": holds the scripts to run the imputation part for the few missing data points in SPAD. We use the outputs in the regression scripts (more results available in Supplements)

"Regression": holds the scripts to run the multiple linear regression part on the whole sample, imputed and non-imputed (more results available in Supplements)

"Classification": holds the scripts to run the Multinomial Logistic Regression part (more results available in Supplements)
